## ✨ Highlights

- **⚡ Infinity Field Continuum**: Smooth real-time scaling from **10,000** to **100,000,000** particles with dynamic sub-pixel clustering.
- **🪐 Multi-Dimensional Manifolds**: Project 2D, 3D, 4D, and 5D geometric attractor fields onto a unified coordinate plane.
- **🧪 Quantum Particle Lab**: Experiment with fundamental species (*electrons, protons, quarks, tachyons*) and physical constraints.
- **🎯 Impulse Canon**: Interactive kinetic projectiles that perturb equilibrium fields with continuous self-healing restorative forces.
- **🌓 Seamless Theme Engine**: Instant zero-ghosting light and dark themes with calibrated contrast and inverted particle matrices.
- **🎮 Hand Navigation**: Smooth camera panning, zoom magnification, and autonomous 3D rotational spin.

## 🕹️ Controls

| Control | Key / Action | Description |
| :--- | :---: | :--- |
| **✋ Hand** | Toggle | Orbit, pan `(X/Y)`, zoom scale, and inspect particle structures |
| **✏️ Pencil** | Toggle | Opens the Universe Architect (Presets, Shapes, Math, Colors) |
| **🔀 Random** | Toggle | Procedural manifold generation across geometries |
| **🎯 Canon** | Click / Drag | Aim and fire impulse projectiles to perturb equilibrium |
| **∞ Infinity** | Slider | Scale density logarithmically from **10K** to **100M** particles |
| **🧪 Lab** | Modal | Tweak mass, charge, spin, species, and custom blank objects |
| **🌓 Theme** | Button | Switch between Dark Cosmos and Light Celestial themes |

## ⚡ Quick Start

```bash
# Clone repository
git clone https://github.com/mahesh953-hub/continuum.git
cd continuum

# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:3000` in your browser.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **State**: Zustand
- **Renderer**: High-Performance 2D Canvas with sub-pixel kinetic integration
- **Styling**: Tailwind CSS + Lucide Icons
